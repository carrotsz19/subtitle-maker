Put one voice clip per person in this folder, named after them:

    Alex.wav
    Jamie.mp3

- 10-20 seconds of that person talking ALONE (no music, no one else talking).
- Any audio format works: .wav, .mp3, .m4a, or even a short .mp4/.mov.
- The file name (without the extension) is the name shown in the subtitles.

The multi-speaker subtitle maker matches each voice it hears to these clips.
Anyone it can't match, it will ask you to name.
